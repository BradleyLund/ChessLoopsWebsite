Replaced it with `<link rel="preconnect">` (googleapis + gstatic) plus a direct `<link rel="stylesheet">` to the same Google Fonts URL, added identically to all three pages' `<head>`, and removed the `@import` from styles.css. Verified via a local server + claude-in-chrome: both fonts (Playfair Display headings, DM Sans body) render correctly on index.html and terms.html, no console errors. Commit e931f06.
